# Zapret GUI

Оконная оболочка (один `.exe`, без консоли) для
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

Всё необходимое (`winws.exe`, драйвер WinDivert, списки, fake-пакеты) вшито в
программу и при запуске распаковывается в `%LOCALAPPDATA%\ZapretGUI`.

## Возможности

- выбор любой из 22 стратегий (`general`, `ALT`…`ALT13`, `EXP`, `FAKE TLS AUTO…`, `SIMPLE FAKE…`);
- кнопка **«Подобрать стратегию»**: перебирает стратегии и оставляет первую, при которой
  открываются Discord (сайт, gateway, CDN) и YouTube (сайт, картинки, googlevideo);
- игровой фильтр (выкл / TCP+UDP / TCP / UDP) и режим ipset (none / loaded / any) — как в `service.bat`;
- тема оформления: **Авто** (как в Windows, меняется на лету), **Тёмная** или **Светлая** — кнопка «Тема» в правом
  верхнем углу; тёмными становятся окно, заголовок, кнопки, списки, журнал и меню в трее;
- значок в трее (серый — остановлено, зелёный — работает), закрытие окна сворачивает в трей;
- автозапуск при входе в Windows через планировщик заданий (с правами администратора, без UAC-запроса);
- кнопка **«Проверить обновления»**: сравнивает версию с `main` репозитория Flowseal и, если есть новее,
  скачивает архив, проверяет его (только нужные файлы, `winws.exe`/DLL — настоящие PE, все файлы из
  стратегий на месте), останавливает защиту, ставит файлы и снова включает её. Если установка прервалась,
  при следующем запуске восстанавливаются встроенные файлы;
- вкладка **«Дополнительно»** — те же возможности, что в меню `service.bat`:
  - **служба Windows** (Install / Remove / Status): защита включается при старте системы, окно не нужно;
    пока служба работает, запуск из окна блокируется, а закрытие окна службу не останавливает;
  - **fake-пакеты** для Discord UDP и для игр (Replace active fakes) — подставляются в аргументы запуска,
    выбор «По умолчанию» всегда возвращает стандартные;
  - **проверка обновлений при запуске** (только сообщает, не устанавливает);
  - **обновить список IP** — скачивает `ipset-service.txt`, проверяет каждую строку и применяет;
  - **обновить / очистить hosts** — добавляет отдельный помеченный блок (с подтверждением и резервной копией
    `hosts.zapret-backup`), остальной файл не трогает;
  - **диагностика** — BFE, прокси, TCP timestamps, конфликтующие программы и службы (Adguard, Killer, SmartByte,
    Check Point, VPN…), DoH, hosts, висящий драйвер WinDivert, другие обходы, путь с кириллицей / в OneDrive;
  - **очистка кэша Discord** (Stable, PTB, Canary, Development);
- свои домены: кнопка «Папка со списками», файлы `list-general-user.txt` и `list-exclude-user.txt`
  не перезаписываются при обновлении.

Не перенесено: «Run Tests» из `service.bat` (PowerShell-скрипт на сотни строк) — его роль выполняет
«Подобрать стратегию».

## Файлы

| Путь | Что это |
|---|---|
| `%LOCALAPPDATA%\ZapretGUI\config.json` | настройки |
| `%LOCALAPPDATA%\ZapretGUI\winws.log` | вывод `winws.exe` последнего запуска |
| `%LOCALAPPDATA%\ZapretGUI\crash.log` | появляется только при внутренней ошибке программы |

## Сборка

```
./build.sh                  # пересобрать
./build.sh /путь/к/репо     # сначала обновить стратегии и бинарники из свежего клона
```

Стратегии не переписаны вручную: `tools/gen_strategies.py` разбирает `general*.bat`
оригинального репозитория, поэтому обновление — это перезапуск скрипта.
Интерфейс написан на чистом Win32 через `syscall`, без внешних зависимостей;
манифест (права администратора, современные контролы) и иконки генерирует
`tools/mkrsrc.py`.

## Лицензии

Программа использует `winws.exe` ([bol-van/zapret](https://github.com/bol-van/zapret)),
WinDivert и скрипты Flowseal; текст лицензии (MIT) кладётся рядом с распакованными файлами.
